
# Assignment 1: Git and GitHub

## Project Overview

This project demonstrates the basic Git and GitHub workflow,
including creating a repository, tracking changes, committing
files, and publishing a project online.

## Objectives

- Create and manage a Git repository.
- Use Git to track changes.
- Practice adding and committing files.
- Push changes to GitHub.
- Write documentation using Markdown.

## Project Files

- `sample_data.py` - A Python script containing sample student
  data and calculating the average student score.
- `README.md` - Project documentation.

## Requirements

- Python 3
- Git
- A GitHub account

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/yeselamaraya-debug/new-project.git
   ```

2. Enter the project directory:

   ```bash
   cd new-project
   ```

3. Run the Python script:

   ```bash
   python sample_data.py
   ```

## Sample Output

The script displays five student records, the total number
of students, and their average score.

## Git Workflow

The project uses the following basic workflow:

1. `git add` - Stage changes.
2. `git commit` - Save a snapshot of the changes.
3. `git push` - Upload commits to GitHub.
4. `git pull` - Download changes from the remote repository.
