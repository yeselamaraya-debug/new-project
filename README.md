
# Assignment 1: Git and GitHub

## Project Overview

This project demonstrates the basic Git and GitHub workflow,
including creating a repository, tracking changes, committing
files, and publishing a project online.

## Objectives

- Create and manage a Git repository.
- Use Git to track changes.
- Practice adding and committing files.
- Push changes to GitHub.
- Write documentation using Markdown.

## Project Files

- `sample_data.py` - A Python script containing sample student
  data and calculating the average student score.
- `README.md` - Project documentation.
